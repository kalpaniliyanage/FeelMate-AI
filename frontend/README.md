
# FeelMate AI

An AI-powered facial expression recognition and
personalized mood-support web application.

## Technologies

- React and Vite
- Python and FastAPI
- Hugging Face Transformers
- PyTorch
- Pillow

## Backend setup

Create a Python virtual environment, install the
backend requirements, and run the FastAPI server.

## Frontend setup

Install dependencies using npm and start the
Vite development server.

## Important

Facial expression predictions do not confirm a
person's actual emotional state.

Use camera access only with the user's permission.
